# Proyek Akhir: Program Rekap dan Analisis Nilai Matematika Kelas

Program berbasis konsol (Python) yang dirancang untuk membantu guru matematika dalam membaca rekap data nilai dari file teks, melakukan validasi, menghitung statistik kelas, menentukan status ketuntasan siswa, dan menghasilkan laporan otomatis.

## Struktur Folder
- `data/`: Berisi file masukan data (`nilai_contoh.txt`)[cite: 10].
- `src/`: Berisi modul utama program (`main.py`, `data_io.py`, `analisis.py`, `utilitas.py`)[cite: 10].
- `tests/`: Berisi dokumentasi pengujian (`test_case.md`)[cite: 10].
- `output/`: Folder penyimpanan hasil laporan ringkas.

## Cara Menjalankan Program
1. Pastikan interpreter Python sudah terinstal.
2. Buka terminal di VS Code pada direktori proyek ini.
3. Jalankan perintah:
   ```bash
   python src/main.py
